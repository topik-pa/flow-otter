Come funziona

Dai dati grezzi alle analisi approfondite in tre semplici passaggi.

1

Carica i tuoi file

Esporta la cronologia delle transazioni da Binance, Bybit, Coinbase e altre piattaforme in formato CSV/XLS, quindi caricala in pochi istanti.

2

Applica i filtri

Seleziona gli exchange e le criptovalute su cui vuoi concentrarti. La visualizzazione dei dati si aggiorna istantaneamente.

3

Esplora i tuoi dati

Analizza le statistiche, utilizza la vista Tabella per i registri dettagliati o la vista Grafo per visualizzare l'andamento delle tue operazioni nel tempo.

FAQ

Coin Otter è gratuito?

Sì — durante la fase MVP, l'accesso anticipato è gratuito.

Quali exchange sono supportati?

I principali exchange come Binance, Bybit e Coinbase tramite file di cronologia esportati. Il supporto viene ampliato in base alla domanda.

Quali formati di file posso caricare?

File CSV e XLS.

Ho bisogno di chiavi API?

No. Coin Otter funziona con i tuoi file di cronologia delle transazioni esportati — non è richiesta alcuna connessione API con l’exchange.

Posso richiedere nuove funzionalità?

Certamente. Gli utenti MVP hanno la maggiore influenza su ciò che verrà sviluppato in futuro.
